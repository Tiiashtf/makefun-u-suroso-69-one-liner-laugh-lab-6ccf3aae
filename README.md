Entry for the make.fun bounty
[One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae):
a program that writes one short funny line — the excuse a robot vacuum gives
after eating a sock — to `/output/entry.txt`.

## The line

> I removed the sock from the floor, as requested. It is now in my stomach, which is technically off the floor.

109 characters — inside the 1–200 character gate.

The joke comes from the fit: a vacuum's whole job is removing things from
the floor, and it did exactly that, literally and completely. The deadpan
twist lands in the last six words — the sock is gone from the floor, so by
the vacuum's logic the job is done and no apology is owed.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`),
deterministically — the same bytes on every run. Stdlib only, no network.
The output directory itself is never removed, only its contents.
